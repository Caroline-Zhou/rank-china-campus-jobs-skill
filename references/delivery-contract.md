# 交付与工作簿契约

## 在线决策表

按综合推荐优先级排序，至少包含：

| 字段 | 要求 |
|---|---|
| 排名、岗位、地点、招聘类型 | 使用官网原始名称 |
| 当前状态、原始链接 | 标记官网本次是否可投；链接指向岗位详情或可复现入口 |
| 匹配度、推荐级别 | 使用统一评分框架，不用模糊赞美替代 |
| 学历要求、官网专业要求、建议专业、语言要求 | 官网专业要求区分必需、优先和未说明；建议专业标记为基于实际竞争的推测 |
| 官网薪资、市场薪资参考 | 官网未披露时不得猜测；市场参考必须注明样本来源、年份、同岗/相邻岗位和可信度 |
| 入职门槛 | 独立评分；高分表示更容易进入 |
| 本科背景敏感度 | 低/中/高，注明“官网证据”或“推测” |
| 硬门槛风险 | PASS / FLAG / FAIL / 未核实，并给依据 |
| 现有优势 | 只写候选人已有且可证明的证据 |
| 主要缺口 | 区分关键词缺失与真实能力缺口 |
| 秋招/实习价值 | 结合当前主投秋招的阶段判断 |
| 投递建议 | 主投、备选、谨慎或不建议，并说明一条核心理由 |

首版表可以缩减为岗位、地点、招聘类型、开放状态、初步推荐和链接；最终表补全所有字段。

## 公司 Sheet

以公司常用中文名命名；存在同名 Sheet 时刷新而非新建重复版本。按以下顺序排版：

1. 标题、官网来源和最后核验时间。
2. 完整岗位决策表。
3. 简短公司介绍。
4. 核心产品。
5. 核心业务线。
6. 恰好 5 条按优先级排序的简历修改建议。

保留用户历史投递状态。用户报告已投递时，在公司 Sheet 与“求职总览”同时更新。岗位从官网消失时改为“已下线/待复核”，不要删除。

## 总览与评分汇总

更新“求职总览”中的公司、优先岗位、最高分、最近刷新日期、当前状态和下一步。若工作簿存在评分汇总或公式依赖，刷新受影响区域并检查公式错误。

## 简历建议边界

只给最能提高该公司或主投岗位匹配度的 5 点，优先涉及：经历排序、量化成果、岗位关键词、业务场景和真实证据补强。不得生成虚构经历，不自动创建或修改简历文件。

## Excel 质量与速度

- 保留原工作簿字体、配色、列宽、冻结窗格、筛选和公式风格。
- 批量完成单次写入，避免反复保存或复制。
- 验证本次新增/改动的公司 Sheet、求职总览和评分汇总；对未改动且已有视觉验证记录的旧 Sheet 不重复渲染。
- 扫描明显公式错误，确认关键链接、日期、状态和中文文本可读。
- 验证后同步到桌面固定路径，并在最终回复中给出可点击的文件链接。
